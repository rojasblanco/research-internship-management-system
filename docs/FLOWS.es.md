# Flujos de incorporación y seguimiento

## 1. Pasantía estándar

```text
Fuente estructurada de postulación
  → horario provisional / PDF
  → revisión y entrevista
  → aceptación
  → cursos de inducción
  → formalización y documentación
  → carpeta personal + Activity Planner + H1
  → seguimiento de actividades / asistencia / horario
  → períodos intermedios automáticos
  → reportes periódicos automáticos
  → revisión final
  → culminación / extensión / retiro
```

Una postulación rechazada se cierra sin crear una persona operativa como pasante.

## 2. Pasantía con posible transición laboral

Sigue el flujo de una pasantía mientras la persona se encuentra en esa etapa. Al final puede existir una decisión de transición laboral registrada de forma separada. La pasantía no garantiza contratación.

## 3. Incorporación directa

Una persona que ingresa por una ruta laboral/administrativa directa no debe simular una pasantía. La integración debe partir de una fuente administrativa autorizada y aplicar únicamente los controles que correspondan.

## Seguimiento por períodos

Los períodos intermedios funcionan como checkpoints automáticos. El sistema consolida y genera el reporte cuando los datos pasan las validaciones. Las inconsistencias quedan visibles como excepciones para revisión.

El cierre final mantiene intervención humana porque puede alimentar decisiones o documentos con mayor consecuencia administrativa.

## Cambio posterior de horario

El horario provisional pertenece a la postulación y H1 al inicio real. Un flujo específico para cambios posteriores H2/H3, sin reutilizar la postulación completa, permanece como extensión futura hasta que sea implementado.
