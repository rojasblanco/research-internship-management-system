# Example data model

This directory contains two equivalent fictitious workbooks:

- `internship_management_database_example_es.xlsx` — Spanish canonical reference names used by the reference implementation.
- `internship_management_database_example_en.xlsx` — English documentation mirror.

Both represent the same public architecture: 21 model sheets plus one visual separator. People, emails, IDs, components, courses, documents, links, and configuration examples are fictitious.

The English workbook is intended for documentation and review. It is not a drop-in replacement for a deployment whose Apps Script readers/writers expect the Spanish canonical sheet/header names.
